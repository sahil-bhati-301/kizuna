## Goal
Give every session a reliable local database and a test harness that isolates it.

## Acceptance criteria (each must be testable)
1. `docker compose up` (via `pnpm db:up`) starts a local PostgreSQL that is healthy within a stated time.
2. Drizzle is configured with a migration command (`pnpm db:migrate`) that applies cleanly to an empty database.
3. A Testcontainers harness starts an isolated Postgres per test run and tears it down.
4. A sample test proves the harness connects, migrates and rolls back between tests.
5. The set-up is documented in the root CLAUDE.md commands list and a package CLAUDE.md.

## Out of scope
- Real module schemas (W01-2, W05-3). RLS policies. Cloud database set-up.

## Packages and files expected to change
- docker-compose.yml
- drizzle.config.ts, packages/persistence scaffolding
- test harness under packages/persistence/test/
- package.json scripts

## Test plan
- Integration: harness test creates a table, inserts, rolls back, and confirms the next test sees a clean state.
- Manual: `pnpm db:up` then `pnpm db:migrate` on a clean machine.
- CI: harness test runs in the W00-2 workflow (Docker available).
