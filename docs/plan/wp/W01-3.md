## Goal
Turn KANJIDIC2 and the Jōyō table into typed kanji and reading rows, with the teach set and official readings marked.

## Acceptance criteria (each must be testable)
1. The parser streams KANJIDIC2 XML into `kanji` rows: literal, codepoint, strokes, classification radical, grade, freq_rank and lang-tagged meanings; nanori are separate `reading` rows of kind `nanori`.
2. Readings pass through the W01-4 normaliser: kana stored in hiragana, okurigana and affix markers split (`た.べる` → stem `た`, okurigana `べる`).
3. Exactly the 2,136 Jōyō kanji get `is_joyo = true`; each reading in the Jōyō table gets `is_joyo = true` on its reading row, and a reading listed only in KANJIDIC2 gets `false`.
4. A Jōyō entry with no matching KANJIDIC2 kanji or reading is reported, not dropped silently.
5. The same inputs give byte-identical output (rows sorted by a stable key; golden file).
6. Every row carries `source`, `source_version` and `license`.
