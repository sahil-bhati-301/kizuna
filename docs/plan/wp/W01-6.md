## Goal
Put the kernel's pure code where the repo-wide purity rules can see it, and drop the kernel's own stand-in check.

## Acceptance criteria (each must be testable)
1. Pure modules (ids, clock and rng types, errors, events) live under `packages/kernel/src/domain/`; the logger and anything with I/O stays outside.
2. `packages/kernel/src/index.ts` exports exactly the same names as before (a test compares the export list).
3. The repo ESLint and dependency-cruiser domain rules cover the moved files; the source-scan stand-in (`purity.test.ts`) is removed or reduced to what the repo rules do not cover.
4. A deliberate `Date.now()` in a kernel domain file fails `pnpm verify:affected` (shown once, then reverted; noted in the PR).
5. The frozen spec-tester tests from W00-5 still pass unchanged apart from import paths.
