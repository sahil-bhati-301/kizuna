## Goal
Create `apps/pipeline` and pin each source by URL, version and checksum, so every later stage starts from known inputs.

## Acceptance criteria (each must be testable)
1. `apps/pipeline` exists as a workspace package with its own CLAUDE.md, and `pnpm verify` covers it.
2. `content/sources.lock.yaml` lists KANJIDIC2 and KRADFILE with URL, version or fetch date, sha256 and licence; a schema check rejects an entry missing any field.
3. The fetcher downloads a source, verifies its sha256 and stores the compressed file in the repo under `content/sources/`; a checksum mismatch exits non-zero with a message naming the source and the re-pin command.
4. A stored file with a matching checksum is not downloaded again, so sessions and CI read the committed copy without network access.
5. dependency-cruiser gains an apps-to-apps rule (backlog, W00-1 review): an app may not import another app.

## Out of scope
- Other sources (KanjiVG, JMdict, JmdictFurigana, Tatoeba): W02, which decides repo or R2 for the larger files. Parsing.

## Packages and files expected to change
- apps/pipeline/ (package.json, CLAUDE.md, src/sources/…, tests)
- content/sources.lock.yaml
- content/sources/ (committed compressed KANJIDIC2 and KRADFILE, with attribution notes)
- .dependency-cruiser.cjs, pnpm-workspace.yaml (apps/*)

## Test plan
- Unit: lock schema validation; checksum match, mismatch and cache hit with a local HTTP stub (no real network).
- Manual: one real fetch once O-5 allows the host.

## OPEN-Q
