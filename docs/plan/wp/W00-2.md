## Goal
Run the verify pipeline in GitHub Actions and protect `main` so only green, squash-merged PRs land.

## Acceptance criteria (each must be testable)
1. A GitHub Actions workflow runs install, lint, typecheck, tests and boundaries on every pull request and on push to `main`.
2. The workflow uses `pnpm verify` and fails the job when it fails.
3. Dependency and Turborepo caches are used; a second run on an unchanged tree is measurably faster.
4. A deliberately failing branch shows a red check; a clean one shows green.
5. Branch protection on `main` requires the CI check and squash merge (owner task O-2; documented in the PR).
