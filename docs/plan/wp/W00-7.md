## Goal
Enforce the daily budget with hooks and make early stops resumable through checkpoints.

## Acceptance criteria (each must be testable)
1. `scripts/claude/budget.mjs` records status-line JSON, checks the budget on hooks, and logs sessions to docs/plan/budget-log.md.
2. `.claude/budget.json` holds thresholds and daily caps; green, amber and red lights follow development-plan §2.2–§2.3.
3. Hooks for SessionStart, PostToolUse, UserPromptSubmit, Stop, PreCompact and SessionEnd are configured as command hooks only.
4. `/checkpoint` writes a WIP commit, overwrites the WP Checkpoint section and sets the STATUS row; `/budget` sets manual figures.
5. `/wp` resumes from a checkpoint at the recorded loop step.
6. Tests use recorded status-line JSON, and every environment in use is tested.
7. `node --test "scripts/claude/*.test.mjs"` is green.

## Out of scope
- Planner and agent logic for anything beyond hooks. Prompt hooks that call a model.

## Packages and files expected to change
- scripts/claude/*
- .claude/settings.json, .claude/budget.json
- .claude/commands/checkpoint.md, .claude/commands/budget.md
- .gitignore

- Fixture: recorded status-line JSON for each environment in use.
