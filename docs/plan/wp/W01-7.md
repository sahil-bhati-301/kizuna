## Goal
Clear the Node 20 deprecation warnings in CI and take the Node version from one place.

## Acceptance criteria (each must be testable)
1. `actions/checkout`, `actions/setup-node`, `actions/cache` and `pnpm/action-setup` use their current majors that run on Node 24; a CI run shows no Node 20 deprecation warning.
2. `.nvmrc` holds the Node version; CI reads it (`node-version-file`) and `engines.node` in the root package.json agrees with it.
3. The required check name stays `verify`, so branch protection keeps working.
4. A green CI run on the PR is linked in the PR.

## Out of scope
- New CI jobs. Caching changes beyond what the version bumps need.

## Packages and files expected to change
- .github/workflows/ci.yml, .nvmrc, package.json (engines only)

## Test plan
- CI: green run on the PR, with the warning gone from the logs summary.
