## Goal
Split the architecture doc once into per-module spec digests so agents never load it whole.

## Acceptance criteria (each must be testable)
1. docs/specs has one digest for each of content, pipeline, memory, insights, drills, account, web and platform.
2. Each digest is 1,500–3,000 words and links every rule back to the architecture doc with an anchor (→ arch §x.y).
3. Formulas, thresholds, tables and invariants are copied word for word; reasoning is dropped.
4. A cross-check pass confirms every number and threshold in the architecture doc appears in exactly one digest; the result is listed in the PR.
5. A short script or checklist reports numbers missing from, or duplicated across, the digests.
6. The owner skims each digest (O-4).

## Out of scope
- As-built refreshes (consolidation weeks). Changes to the architecture doc itself.

## Packages and files expected to change

- scripts/ cross-check helper (if scripted)
