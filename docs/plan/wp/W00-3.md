## Goal
Create the root rules, agent and command definitions, PR template and planning documents that make sessions cheap and repeatable.

## Acceptance criteria (each must be testable)
1. Root CLAUDE.md is under 150 lines and matches Appendix C, with the note that verify scripts arrive in W00-1.
2. Seven agent files exist in .claude/agents with valid frontmatter (name, description, tools, model, effort) and each body is short.
3. Commands wp, plan-week, retro, gate and hotfix exist in .claude/commands, each under 30 lines, with description, argument-hint and model.
4. Every long-running agent (implementers, spec-tester, reviewer) has the budget-notice rule.
5. .github/pull_request_template.md matches template A.4.
6. docs/plan has STATUS.md (60 lines or fewer), roadmap.md, backlog.md, budget-log.md, adr/README.md, weeks/W00.md and wp/W00-1..7.md.
7. Frontmatter field names and model values are checked against current Claude Code documentation before the PR is merged.

## Out of scope
- Hooks, settings, budget guard and /checkpoint, /budget (W00-7). Package-level CLAUDE.md files (created with each package). Spec digests (W00-4).
