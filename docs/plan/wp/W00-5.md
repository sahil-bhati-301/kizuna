## Goal
Provide the small, pure foundation every module depends on, with injected time and randomness.

## Acceptance criteria (each must be testable)
1. `kernel` exports UUIDv7 ID generation that is time-ordered and valid under the UUID v7 layout.
2. An injected `Clock` interface has system and fixed/fake implementations; no other code reads `Date.now()`.
3. A seeded RNG gives the same sequence for the same seed and is injectable.
4. Typed errors, a logger interface and base event types are exported through `src/index.ts` only.
5. `domain/` code in kernel has no I/O, no `Date.now` and no `Math.random`, enforced by lint or dependency-cruiser.
6. Property tests cover ID ordering and RNG determinism.

## Out of scope
- Persistence, outbox and concrete event definitions (contracts, W05). Any module other than kernel.

## Packages and files expected to change
- packages/kernel/src/{ids,clock,rng,errors,logger,events}.ts and src/index.ts
- packages/kernel/CLAUDE.md
- packages/kernel/**/*.test.ts

## Test plan
- Unit: UUIDv7 version and variant bits; clock fake advances only when told.
- Property (fast-check): IDs generated in order sort in order; same seed gives same RNG sequence; different seeds diverge.
- Boundary: lint rule rejects `Date.now` and `Math.random` in domain code.
