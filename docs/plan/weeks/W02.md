EDRDG regenerates JMdict daily, so the URL cannot re-serve a pinned version. Options: (a) commit every pinned compressed file under `content/sources/` as now, raising a new OPEN-Q for any file over 50 MB; (b) Git LFS (CI checkouts count against the 1 GB/month free bandwidth); (c) commit a deterministic filtered subset (e.g. Tatoeba English sentences linked to Japanese only) with the upstream checksum pinned, like the Jōyō `transcribed:` entry. Recommendation: KanjiVG a (no owner step, deterministic); JmdictFurigana a (one upload, about 5 min). Blocks only the lock pins and full-file runs of W02-1 and W02-3; fixtures are unaffected.
