# Architecture decision records

One file per decision: `ADR-0001-<slug>.md`, numbered in order (ADR-0001, ADR-0002, …). Never renumber.

A change of design goes: ADR, then the architecture doc, then the spec digest, in the same PR. The architecture doc wins any conflict.

## Format
```
# ADR-NNNN: <title>
Status: proposed | accepted | superseded by ADR-NNNN · Date: <yyyy-mm-dd>

## Context
What forces the decision. Link the architecture section.

## Decision
What we chose, in plain words.

## Consequences
What gets easier, what gets harder, what to revisit and when.
```
